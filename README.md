# 🦁 Organizador de Declaração de Imposto de Renda - Lion App

Este projeto consiste em uma ferramenta robusta e automatizada desenvolvida inteiramente no **Microsoft Excel** com suporte de IA (**Microsoft Copilot**). O objetivo principal é atuar como um agregador e organizador de dados essenciais para simplificar o processo de declaração do Imposto de Renda de Pessoa Física (IRPF).

A ferramenta conta com uma interface amigável (estilo Dashboard/Sistema), navegação intuitiva e mecanismos de validação automatizada para mitigar erros de digitação.

---

## 🚀 Funcionalidades Principais

* **Menu Lateral de Navegação:** Interface limpa e integrada para transição rápida entre as abas (`Titular`, `Informes` e `Notas`).
* **Validação de Dados:** Aplicação de regras estritas do Excel para garantir que campos críticos (como CPF, datas e valores numéricos) sejam preenchidos no formato correto.
* **Interface Assistida (Campos Destacados):** Uso de paleta de cores funcional para indicar visualmente ao usuário onde os dados devem ser inseridos, bloqueando células com fórmulas para evitar alterações acidentais.
* **Agrupamento de Informações:** Centralização de dados do titular, dependentes, cônjuge, informes de rendimentos e notas fiscais em um único ecossistema.

---

## 🛠️ Tecnologias e Recursos Utilizados

* **Microsoft Excel:** Fórmulas de data, formatação condicional, validação de dados e congelamento de painéis.
* **Microsoft Copilot:** Suporte no planejamento de layout, validação de regras de negócios e geração de insights para fórmulas complexas.
* **Markdown:** Estruturação visual desta documentação técnica.

---

## 📂 Estrutura das Abas da Planilha

1. **TITULAR:** Centraliza as informações civis do contribuinte, incluindo CPF, Título de Eleitor, dados do Cônjuge e validação de residentes no exterior.
2. **INFORMES:** Espaço dedicado para consolidação de rendimentos tributáveis, recebidos de pessoas jurídicas, retenções na fonte e saldos bancários.
3. **NOTAS:** Registro e histórico de despesas dedutíveis (saúde, educação, previdência) para cruzamento posterior com a declaração oficial.

---

## 📋 Como Utilizar a Ferramenta

1. Faça o download do arquivo `.xlsx` presente neste repositório.
2. Abra o arquivo no Microsoft Excel (recomendado utilizar a versão Microsoft 365).
3. Preencha apenas as células destacadas em amarelo claro na aba **TITULAR**.
4. Utilize o menu ou os navegadores inferiores para alimentar as abas de **INFORMES** e **NOTAS**.
